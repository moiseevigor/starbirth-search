# Class 0 protostar

> **Concept hub.** This note exists as a shared anchor — multiple paper summaries link here via their `key_concepts` frontmatter, so reading this gives the cross-paper view of one idea. Keep it short and authoritative. Long discussions go in paper notes, not here.

## Definition

The youngest observational class of protostar: a central source deeply embedded in an envelope that still holds most of the mass. Operationally, Class 0 means [[bolometric-temperature]] T_bol < 70 K (Chen et al. 1995 boundary, used by [[dunham-2014]] and [[furlan-2016]]) and/or a large submillimetre luminosity fraction, L_smm/L_bol > 0.5% (André et al.; used by [[stutz-2013]]).

"Class" is an observed SED category, not a physical "Stage". [[dunham-2014]] stresses that class does not map one-to-one onto stage, and [[furlan-2016]] (§VIII) finds "the observed classes contain a mixture of evolutionary stages", because inclination and foreground extinction move sources between classes.

## Why it matters

Class 0 is the phase closest to protostellar birth that surveys can count. Its duration sets how many newborn protostars a survey should contain, and it is where the youngest outbursts and the steepest luminosity evolution are seen.

## Cross-paper view

- **Duration:** 0.16 Myr (0.10 extinction-corrected) ([[evans-2009]]); 0.15–0.16 Myr from a Class 0 fraction of 0.30–0.32 ([[dunham-2014]]); half-life 47±4 kyr without steady state ([[kristensen-dunham-2018]]); the "genuine class 0" phase T_bol < 70 K lasts ≲2×10⁴ yr after birth in 1-D RHD ([[masunaga-inutsuka-2000]]).
- **Census (Orion HOPS):** 92 Class 0 of 330 protostars, median L_tot 5.5 L⊙ ([[furlan-2016]]); 73/92 measured at 4.5 µm, 14/92 at K_s (vault-derived, [[furlan-2016]]).
- **Extreme subsets:** [[pacs-bright-red-source]]s ([[stutz-2013]]); [[vello]]s ([[dunham-2008]]).
- **Theory link:** [[tomida-2013]] and [[young-2023]] follow the object from [[second-collapse]] into the Class 0 phase; luminous cold sources are genuine Class 0 while faint cold ones may be edge-on Class I ([[masunaga-inutsuka-2000]]).
- **Variability and bursts:** first Class 0 outburst, HOPS 383 ([[safron-2015]]); Class 0 burst interval 438 yr (95% CI 161–1884 yr; [[zakri-2022]]); 38% of bright Class 0 vary at 850 µm, indistinguishable from Class I ([[lee-2021]]); protostellar outburst rates in [[fischer-2019]], [[park-2021]].
- **Galactic plane:** low-luminosity Class 0 objects can hide in Hi-GAL "starless" clumps below the 70 µm floor ([[elia-2017]], [[elia-2021]]).
- FHSC candidates must be distinguished from very faint Class 0 sources ([[enoch-2010]]).

## Open questions

- The Class 0 duration differs by a factor ~3 between steady-state and non-steady-state readings of the same counts (0.16 Myr vs 47 kyr).
- How much of the Class 0 population is contaminated by edge-on Class I sources, and vice versa?
