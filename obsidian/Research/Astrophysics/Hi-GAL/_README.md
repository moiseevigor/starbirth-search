# Hi-GAL

Paper notes on the Herschel infrared Galactic Plane Survey (Hi-GAL): the DR1 maps and single-band compact-source catalogues ([[molinari-2016]]), the physical clump catalogues ([[elia-2017]] inner Galaxy, [[elia-2021]] 360°), and the Hi-GAL Milky Way SFR ([[elia-2022]]).
Key hub: [[hi-gal-evolutionary-classification]]. The protostellar = 70 µm-detected rule is photometric only. It is biased by the ~0.2 Jy 70 µm sensitivity floor (which misses low-luminosity protostars beyond ~5 kpc) and by beam blending at large distance.
Always check which distance set (Russeil 2011 vs Mège 2021) and which reliability list a number comes from.
