# Lifetimes

Paper notes on **statistical phase lifetimes** of early star formation: number-count ratios of starless/prestellar cores or clumps, Class 0, Class I, Flat and Class II sources, converted to durations by anchoring to a reference clock (usually the Class II half-life of ~2 Myr, or a methanol-maser/UCHII lifetime for high-mass regions).
Covers low-mass Gould Belt clouds ([[enoch-2008]], [[evans-2009]], [[konyves-2015]], [[kristensen-dunham-2018]]) and Galactic-plane massive clumps ([[svoboda-2016]], [[battersby-2017]]).
The main caveats are the steady-state assumption, which reference clock is used, and the density/mass dependence of lifetimes. The concept hub is [[statistical-lifetime]].
